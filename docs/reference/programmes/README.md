# Cache de référence — Programmes officiels de l'Éducation nationale

## But

Ce dossier stocke des **extraits synthétiques** des programmes officiels du
ministère de l'Éducation nationale pour les niveaux CE2 et CM1. Ils servent de
référence locale aux agents-conseils (notamment `pedagogue-primaire`) afin
de vérifier la conformité pédagogique d'une leçon **sans aller en ligne** à
chaque session.

**Convention : source locale d'abord, web seulement pour ce qui manque.**
Avant de fetcher eduscol, consulter les fichiers ci-dessous. Compléter en
ligne uniquement si une notion n'est pas couverte ici.

## Note de maintenance

Les programmes sont **stables** : ils ne changent qu'en cas de réforme
publiée au Bulletin officiel. Il n'est pas nécessaire de re-vérifier à chaque
session.

**Re-vérifier uniquement si** :
- une réforme est annoncée (BO spécial ou arrêté ministériel) ;
- une notion semble absente ou contredite par une source pédagogique récente.

En cas de mise à jour, **conserver les en-têtes source + date** de chaque
fichier et mettre à jour la date de récupération.
