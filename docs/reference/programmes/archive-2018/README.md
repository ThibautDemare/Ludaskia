## Note sur la structure des programmes 2018

Les programmes 2018 sont organisés **par cycle** (cycle 2 = CP-CE1-CE2 ;
cycle 3 = CM1-CM2-6e). Ils définissent des **attendus de fin de cycle**
(pas d'année) et des contenus valables pour l'ensemble du cycle.

Les **repères de progressivité annuels** (par classe : CE2, CM1, etc.)
ont été publiés séparément dans le **BO n° 22 du 29 mai 2019** — non
reproduits ici car ce document portait sur les disciplines dans leur
ensemble et dépassait le périmètre de ce cache. Les fichiers ci-dessous
indiquent explicitement cette limite.
